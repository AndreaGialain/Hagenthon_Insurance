Le barriere di Mario

👁 Visiva

Font piccoli, icone non leggibili, aree cliccabili minuscole. Legge testi solo sopra i 20pt.

✋ Motoria

Click precisi impossibili col tremore essenziale. Drag and drop impraticabile.

🧭 Cognitiva

Navigazione a breadcrumb incomprensibile. Nessun feedback vocale. Paura di fare errori irreversibili.

La Soluzione

Un companion vocale
che si adatta a te

VoceGuidata si inserisce nel portale come pannello laterale accessibile. Legge le istruzioni ad alta voce, suggerisce shortcut da tastiera e aumenta il dettaglio ad ogni difficoltà.

🎙️

TTS Audio-First

Voce italiana neurale. Web Speech API + OpenAI TTS-HD opzionale. Funziona senza API key.

⌨️

Shortcut Tastiera

Alt+[lettera] per ogni azione principale. Tab con focus highlight viola ad alto contrasto.

🤖

Intelligenza Adattiva

Claude AI genera istruzioni personalizzate. Fallback statico sempre disponibile offline.

🔄

Escalation Progressiva

Orientamento → guida → shortcut. Il dettaglio aumenta automaticamente ad ogni blocco.

✓ aria-live, aria-label su tutti i controlli interattivi

Capability Agentica

Block Detection + Adaptive Output

Adaptive Evidence

Come cambia il messaggio
allo step Documenti

stuckCount = 0 (primo arrivo)
"Vedi la lista dei tuoi documenti. Cerca e seleziona Attestato di Rischio RC Auto."

→ Orientamento · breve · nessun shortcut

Obiettivo

L'utente ha appena cambiato step. Ha bisogno di orientarsi, non di dettagli. Messaggio breve e contestuale.

stuckCount = 1 (dopo 1 blocco)
"L'Attestato di Rischio è il primo documento della lista. Clicca su di esso o premi Tab per raggiungerlo."

→ Dettaglio · percorso alternativo (Tab)

Adattamento

L'agente rileva difficoltà. Aggiunge dove si trova il documento e offre alternativa al click.

stuckCount ≥ 2 (blocco persistente)
"Scorciatoia: premi Alt+R sulla tastiera. L'Attestato verrà selezionato automaticamente."

→ Shortcut in primo piano · azione immediata

Adattamento massimo

Il mouse è inutilizzabile. L'agente porta la shortcut in primo piano come soluzione definitiva. Testo grande + voce shortcut.

Roadmap

Limiti attuali e prossimi passi

⚠️ Limiti del prototipo

• Portale simulato: integrazione reale richiede SDK del portale assicurativo

• API key lato browser: produzione richiede backend proxy sicuro

• No persistenza: stato resettato ad ogni sessione

• Solo italiano: supporto multilingua da aggiungere

• TTS variabile: dipende dalle voci installate (mitigato con OpenAI TTS)

🚀 Roadmap

• SDK integrabile: snippet JS su qualsiasi portale via attributi HTML

• Profilo persistente: preferenze voce, font size, shortcut custom

• Analytics accessibilità: heatmap dei blocchi per team UX

• Computer vision: rilevamento automatico elementi via screenshot + AI

• App mobile: companion vocale per portali su smartphone
